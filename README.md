# ربات بله‌ی رشدینک

امکانات برای کاربر: تحلیل رایگان سایت (از همان API سایت)، پلن‌ها و قیمت، کد تخفیف فعال، نکته‌ی سئو، درخواست مشاوره، دکمه‌ی ورود به سایت.
امکانات برای مدیر: `/stats` آمار و منبع ورود، `/leads` آخرین درخواست‌های مشاوره، `/broadcast متن` ارسال تبلیغ برای همه‌ی کاربران (با پیش‌نمایش و تأیید).

## ساخت ربات در بله
1. در بله با `@botfather` گفتگو کن و دستور ساخت ربات را بزن؛ یک **توکن** می‌گیری.
2. شناسه‌ی عددی خودت را بگیر (مثلاً با ربات‌های «شناسه‌ی من») تا مدیر ربات باشی.

## راه‌اندازی روی Render
1. این ریپو را در Render به‌صورت Web Service وصل کن. Build: `npm install` ، Start: `npm start`.
2. در Environment این‌ها را بگذار:

| نام | مقدار |
|---|---|
| `BALE_BOT_TOKEN` | توکن ربات (الزامی) |
| `ADMIN_IDS` | شناسه‌ی عددی تو؛ چند نفر با کاما |
| `DATABASE_URL` | اختیاری ولی توصیه‌شده؛ رشته‌ی اتصال Postgres (اتصال **External**). بدون آن، کاربران با هر ری‌استارت پاک می‌شوند و `/broadcast` فقط برای کسانی کار می‌کند که بعد از آخرین ری‌استارت پیام داده‌اند |
| `SITE_URL` | پیش‌فرض `https://roshdink.ir` |

`PUBLIC_URL` را لازم نیست بگذاری؛ Render آدرس را خودش می‌دهد و ربات با وب‌هوک کار می‌کند. اگر وب‌هوک جواب نداد، خودش به polling برمی‌گردد.

## نکات مهم
- **Render رایگان بعد از ۱۵ دقیقه بی‌کاری می‌خوابد.** با وب‌هوک، با اولین پیام بیدار می‌شود ولی ممکن است تا حدود یک دقیقه دیر جواب بدهد. برای جلوگیری، یک پینگ هر ۵ دقیقه به آدرس سرویس (مثلاً با UptimeRobot) بگذار.
- اگر سرور Render به `tapi.bale.ai` وصل نشد (لاگ‌ها خطای اتصال نشان می‌دهند)، همین پروژه را روی میزبان داخل ایران (مثلاً لیارا) اجرا کن؛ کد فرقی نمی‌کند.
- هر نفر در ساعت حداکثر ۳ تحلیل می‌گیرد (`ANALYZE_LIMIT_PER_HOUR`) تا سهمیه‌ی گوگل تمام نشود.
- برای تبلیغات: لینک ربات را با پارامتر منبع بساز، مثلاً `ble.ir/نام_ربات?start=instagram`؛ منبع هر کاربر در `/stats` دیده می‌شود. (پشتیبانی بله از پارامتر start را قبل از کمپین تست کن.)
- `/broadcast` را فقط برای کاربرانی بزن که خودشان ربات را شروع کرده‌اند و متن را کوتاه و مفید بنویس، وگرنه ربات را مسدود می‌کنند.
